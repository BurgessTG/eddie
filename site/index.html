The editor that watches the footage for you.

Eddie finds every shot and every spoken word in your footage, on your own computer. Cut it together by hand, or let any AI agent edit it while you watch.

The editor

Fast on any machine.
Measured, not guessed.

Rust from end to end, with a GPU-drawn interface and FFmpeg built in. No account, no upload, no cloud needed.

🎬

Every shot, found

Curate checks every frame for real cuts, ignoring flashes, lighting changes and things passing the lens, then ranks the best ranges.

🗣️

Every word, local

Whisper transcribes on your machine, on Metal on a Mac or CUDA and Vulkan on Linux, with word timing for cuts that never clip a sentence.

✍️

Captions that keep up

Generated captions in five styles, including one that lights each word as it is spoken. Identical in preview and export.

🎚️

Sound that sits right

Music ducks under speech, Clean voice tames a mic, and every export lands at -16 LUFS, the level the preview plays at.

🧲

A timeline with lanes

Titles, video and sound each get their own lanes. Snap, trim, split, swap, detach audio for J and L cuts, undo anything.

⚡

Light on weak hardware

0.2% CPU at idle. Hardware decode takes 4K HEVC playback from six cores to half of one. Short cuts are prerolled so they play straight through.

For agents

No AI inside.
Bring your own.

Claude Code, Codex, Amp or your own script edits through the eddie command. Every command prints JSON, every edit applies whole or not at all, and the agent checks its work in pictures.

  • Live with the window. Commands reach an open Eddie, so you watch each edit land, and each one is a single Undo.
  • Found without asking. eddie editors lists every open window, saved or not.
  • Sandboxed scripts. JavaScript with no file, network or OS access, under time and memory limits.
  • A guide built in. eddie guide prints the rules an agent follows, each one from a real mistake.
agent@studio
$ eddie new talk.eddie footage/*.mp4 music.wav
$ eddie curate talk.eddie      # shots, transcript, ranked ranges
$ eddie run talk.eddie -e '
  const best = sweepCandidates()
    .filter(c => c.category === "talking")
    .slice(0, 6);
  let at = 0;
  for (const c of best) {
    addAssetRange(c.asset, at, c.sourceIn, c.duration);
    at += c.duration;
  }'

Install

Get Eddie.

Signed and notarized on the Mac, and it updates itself from then on.

macOS

Apple Silicon, macOS 11 or later. Download, unzip and drag Eddie to Applications. Settings → Updates chooses releases or previews.

Download for Mac
Apple Silicon · macOS 11 or later

Linux

Wayland or X11. On Arch, this builds the latest master as a package with its desktop entry. AUR packages follow every release.

mkdir eddie-pkg && cd eddie-pkg && curl -LO https://raw.githubusercontent.com/BurgessTG/eddie/master/packaging/aur-git/PKGBUILD && makepkg -si

Needs FFmpeg 9, ALSA, GTK 3, clang and cmake. See the README.
